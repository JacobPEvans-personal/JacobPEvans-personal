# JacobPEvans Profile README

This is the GitHub profile repository for
[@JacobPEvans](https://github.com/JacobPEvans). The `README.md` renders as the
profile page at <https://github.com/JacobPEvans>.

## Repository Structure

- `README.md` — Profile README displayed on the GitHub profile page
- `metrics.svg` — Static GitHub metrics snapshot (on `output` branch,
  regenerated by `metrics.yml`)
- `renovate.json` — Dependency update automation config
- `LICENSE` — Apache 2.0
- `.markdownlint-cli2.yaml` — Markdown linting rules
- `.readme-validator.yaml` — Validates required README sections on PRs
- `.github/workflows/` — Automation:
  - `snake.yml` — Contribution snake animation → `output` branch
  - `metrics.yml` — GitHub metrics SVG → regenerates `metrics.svg` on
    `output` branch
  - `3d-contrib.yml` — 3D contribution calendar → `output` branch
  - `ci-gate.yml` — Runs markdown lint, file size, and section checks on PRs

## Key Branches

- `main` — Source of truth; all manual edits go here
- `output` — **Auto-generated only**; never edit manually

## Editing the Profile README

1. Edit `README.md` on `main`
2. CI gate validates markdown lint and required sections (`### About Me`)
3. Generated assets (snake, metrics, 3D contrib) update on their own
   schedules via Actions
